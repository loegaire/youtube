# Terminal machine direction

Dark blue-black terminal worlds rather than flat black. Code is large, generous,
and monospace. Warm white is the interpreter core; green always means input remains
data; orange means formatting instructions; red is a write or an unsafe boundary;
blue is memory; purple is an address/pointer; pale cyan is printed output.

The camera's current travels left. Every scene keeps one mechanism active: scanner,
counter, shelf, pointer, byte cells, or gate. Use rounded panels, thick 2px rules,
quiet scanlines, grids, registration labels, and a slight radial glow. Never reserve
a subtitle band and never treat the design as a series of slides.
