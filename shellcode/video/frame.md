# Bytes under the spotlight

The film is a tactile miniature computing lab built from flat opaque objects. Memory
is a shelf, control flow is a rail, the return address is a ticket, the program
counter is a hard-edged spotlight, and defenses are mechanical gates.

Mint marks safe data and confirmed state. Amber marks decoding, attention, and
instructions. Coral marks pressure, boundary crossings, and corruption. Warm white
carries the explanation.

The visual current travels left. Scene changes reuse a carrier—a byte bead, the
spotlight head, a ticket, or the train—so the 21-minute film reads as one continuous
machine. Every scene advances through three to five causal states rather than idling.

Do not use gradients, glass, blur, glow haze, distorted textures, blue/purple neon,
tiny type, decorative card grids, or operational exploit values.
