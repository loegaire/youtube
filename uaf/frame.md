# UAF: When Freed Memory Still Has a Job

## Visual system

- Canvas `#0A0D0B`; opaque terminal and heap surfaces only.
- Mint `#8CCB9A` marks live / valid state; amber `#D8BE73` marks code and allocator decisions;
  coral `#F0786E` marks freed / unsafe memory; off-white `#F1F3EE` is primary copy.
- Code, addresses, and captions use JetBrains Mono Nerd Font. Explanatory copy uses Inter.
- No gradients, glow, glass, blue or purple cyberpunk treatment, background blur, or decorative grids.

## Scene rule

There is no hero frame and no recurring on-screen object. Every scene gets a fresh visual
metaphor, composition, and animation grammar. The narrative sequence and the flat visual
system connect the film; visual elements do not persist across scene cuts.

Examples: a receipt-and-bin conveyor for lifetime, a source microscope for provenance, an
address switchboard for indirect dispatch, a one-slot ticket machine for allocator reuse,
a byte loom for overlapping writes, an instruction theater for the call, and a clean
ownership ledger for the repair.
