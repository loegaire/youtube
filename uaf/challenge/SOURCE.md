# Challenge provenance

Selected challenge: PicoCTF 2021, **Unsubscriptions Are Free**.

Original PicoCTF artifact URLs:

- `https://mercury.picoctf.net/static/95f0b63e520ae2beece2ca11235808f8/vuln`
- `https://mercury.picoctf.net/static/95f0b63e520ae2beece2ca11235808f8/vuln.c`

The original static host no longer resolved on 2026-07-26. The source in this directory
was recovered from the public preservation gist at
`https://gist.github.com/philzook58/47a9e1d63c2b5551cc0168bb22ebf8c9`
and checked against the complete source embedded in Dvd848's PicoCTF 2021 write-up.

`challenge/vuln` is a local reproducible 32-bit build of that recovered source. It is not
claimed to be byte-identical to the unavailable original binary. `challenge/flag.txt` is
an explicit local teaching placeholder and is never presented as a real PicoCTF flag.
