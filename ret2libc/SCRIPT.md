# Ret2libc: the echo server that leaks its own library

This production preserves the supplied lesson and timings. It adds only connective narration so
the 19:20 visual plan has a natural spoken pace. No invented terminal, disassembly, address, or
shell output appears. The final runtime segment is intentionally a real loader failure.

## Editorial runtime decision

The workspace provides `vuln`, not a filename literally called `vuln(1)`, so it was copied to
`evidence/vuln`. The provided `libc.so.6` fails under the host loader with the captured
`_dl_call_libc_early_init` assertion. There is no `exploit.py`, remote endpoint, or matching
loader in this workspace. Therefore the final chapter is a labeled runtime constraint, not a
fabricated stage-one leak or shell transcript.
